A local-first alternative to Firecrawl & Jina Reader

Clean web content.
Fast Rust. Yours to keep.

Turn webpages into clean Markdown, plain text, or structured JSON—ready for developers, AI agents, and RAG pipelines. No hosted extraction API in the middle.

GitHub Get started →

The CLI fetches public URLs over the network; extraction and formatting happen on your machine.

terminal

# Extract readable Markdown

$ extractrs https://example.com

# Feed structured content to your tools

$ extractrs https://quotes.toscrape.com \

--format json --pretty

"title": "Example Domain",

"content": "# Example Domain...",

"url": "https://example.com",

"metadata": { ... }

Why Extractrs

The useful part of the web.
Without the extra baggage.

A focused extraction tool that fits into the way you already build.

Local-first by design

No account or hosted extraction API. Your output stays in your workflow and on your machine.

Native Rust performance

A compiled CLI with bounded response sizes and concurrent batch requests—without a browser to launch.

Privacy, without the proxy

Page content is processed locally, not sent to an extraction service. Fetching a URL still requires internet access.

Clean Markdown

Useful headings, links, lists, and code—without common page clutter. Plain text and JSON are ready too.

One simple binary

A straightforward command-line interface, stdout/file output, and no browser automation setup.

AI- and RAG-ready

Structured metadata, JSON Lines, schema-guided fields, and overlapping content chunks for downstream tools.

A tiny CLI, a clean interface

From URL to useful output.

Readable by people, structured for programs, and easy to pipe into whatever comes next.

Markdowndefault

# Run

$ extractrs https://example.com

# Output

# Example Domain

This domain is for use in illustrative examples in documents. You may use this domain in literature without prior coordination or asking for permission.

[More information...](https://www.iana.org/domains/example)

Structured JSON--pretty

# Run with a real article page

$ extractrs https://quotes.toscrape.com \

--format json --pretty

{
  "title": "Quotes to Scrape",
  "content": "# Quotes to Scrape\n...",
  "url": "https://quotes.toscrape.com",
  "metadata": { ... }
}

Illustrative output shape; extracted content and metadata vary by page.

Made for your existing workflow

Batch URLs, save to a file, or create overlapping chunks for retrieval.

extractrs https://example.com --chunk-size 1200 --overlap 150
